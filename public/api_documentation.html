PhysioCare API Reference

Unified API reference manual for both the Patient PWA and Therapist Portal applications.

Global Setup & Base URLs Config

The API endpoints are served from a unified back-end server. The API services use Axios wrappers with request/response interceptors to attach auth tokens and log request transactions.

Server Base Targets

Live Production API Server

https://api.ccmstestserver.online

AWS S3 Storage Base Bucket

https://physiocare-prod-storage.s3.ap-south-1.amazonaws.com

Local/Testing Fallback

http://3.7.216.95:9090

AWS S3 Media Upload Service Utils

Media files (before/after images, home exercise videos, and therapist voice notes) are uploaded directly from the browser/PWA to an AWS S3 bucket in a three-step process.

GET /api/s3/upload-url?fieldName={fieldName}&extension={extension}&fileSize={fileSize}
Therapist: src/Utils/S3UploadService.js

Step 1: Generates a secure, temporary presigned URL from the server for S3 uploads.

Query Parameters

NameTypeDescription
fieldNameStringe.g. voiceRecord, beforeImage
extensionStringe.g. mp3, jpg, mp4
fileSizeNumberFile size in bytes

Response Details

{
  "uploadUrl": "https://physiocare-prod-storage.s3.ap-south-1.amazonaws.com/uploads/voiceRecord-1725515324545.mp3?AWSAccessKeyId=...",
  "fileKey": "uploads/voiceRecord-1725515324545.mp3",
  "contentType": "audio/mp3"
}
PUT {uploadUrl}
Direct AWS S3 Integration

Step 2: Submits the raw binary file as a PUT request body directly to the generated AWS S3 URL.

axios.put(uploadUrl, fileBlob, { headers: { "Content-Type": contentType } })
GET /api/s3/validate-upload?fileKey={fileKey}&fieldName={fieldName}
Therapist: src/Utils/S3UploadService.js

Step 3: Tells the back-end to inspect the bucket, verify the file successfully landed, and return its validity state.
